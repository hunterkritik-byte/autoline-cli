# Contributing to AutoLine

Thanks for helping improve AutoLine. Contributions are welcome through focused pull requests.

## Development

1. Install Go 1.21 or newer.
2. Clone the repository and run `go mod tidy`.
3. Run `go test ./...` and `go vet ./...` before submitting changes.
4. Keep detector logic deterministic and generators idempotent.

## Pull requests

Explain the problem, describe the implementation, and include tests for behavior changes. Keep commits focused and avoid unrelated formatting changes.

## Code of conduct

Be respectful, constructive, and security-conscious. Never include secrets, credentials, or real production data in issues, tests, or pull requests.
