Quickstart

Install the CLI, enter a repository, and preview what AutoLine detects.

go install github.com/hunterkritik-byte/autoline-cli/cmd/autoline@latest cd your-project autoline scan . --dry-run --json

Generate delivery assets when the preview looks correct:

autoline scan . --provider=github

CLI commands

scan

Detect a workspace and generate delivery assets.

insights

Run optional Python repository intelligence.

languages

Inspect supported language and ecosystem signals.

doctor

Validate local Git, Docker, and toolchain prerequisites.

autoline scan . --dry-run autoline scan . --force --provider=gitlab autoline insights . --json autoline languages --json autoline doctor --json
