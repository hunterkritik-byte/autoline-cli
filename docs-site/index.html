A focused CLI surface

Small commands that compose well in local development, CI, and platform automation.

scan

Detect workspace structure and generate delivery assets.

insights

Run optional Python repository intelligence.

languages

Inspect supported language and ecosystem signals.

doctor

Check local prerequisites and environment readiness.

--json

Produce stable machine-readable output for automation.

--dry-run

Review planned changes without modifying the repository.

Simple core. Powerful extensions.
