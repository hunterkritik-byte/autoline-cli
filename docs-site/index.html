Install once. Run anywhere.

The simplest path is Go's standard installer. The important part is making sure Go's binary directory is on your shell PATH.

01 / INSTALLInstall AutoLine with GoRequires Go 1.25+.
02 / PATHExpose the executableGo installs AutoLine under $(go env GOPATH)/bin unless GOBIN is configured.
03 / VERIFYCheck the local toolchainUse doctor before generating delivery assets.
# Install the latest release
go install github.com/hunterkritik-byte/autoline-cli/cmd/autoline@latest

# Make the Go bin directory available in this shell
export PATH="$(go env GOPATH)/bin:$PATH"

# Verify installation
command -v autoline
autoline --help
autoline doctor
Installed but command not found?
If ls "$(go env GOPATH)/bin/autoline" finds the executable, installation succeeded. Your shell only needs the PATH export above.

Termux-friendly

The Go installer works in Termux. Add $(go env GOPATH)/bin to PATH and persist it in ~/.bashrc or ~/.zshrc.

The autoline insights specialist requires Python 3. Normal Go scanning does not depend on Python.

Why preview first?

--dry-run shows what AutoLine would generate without writing files. Existing generated assets are protected unless you explicitly pass --force.


Need automation?

Add --json for machine-readable scan, language and diagnostic output suitable for scripts and CI.

Safety model: AutoLine reads manifests and repository signals during scanning. It does not execute your project's build, test, or start commands as part of a normal scan. Always review generated assets for your own production requirements.
